### Project Structure

- **.agents**: Configuration files for agents or automation scripts.
- **.github**: GitHub-related configuration files, such as CI/CD workflows.
- **dist**: Directory for built or compiled output files.
- **node_modules**: Node.js modules and dependencies.
- **public**: Publicly accessible files, such as static assets.
- **src**: Source code for the main application.
- **src-tauri**: Source code for the Tauri application (a framework for building desktop applications with web technologies).
